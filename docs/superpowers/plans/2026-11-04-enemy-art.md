# Enemy art: the Moss Creep gets its real animations

Status: approved by the owner (2026-11-04). Source of truth: a study page written in Task 1 (`docs/study/17-enemy-art.md`).

## Goal

The Moss Creep is drawn with Silksong's own art (`MossBone Crawler Anim` in the export) instead of a placeholder shape: walk, turn, death, and the existing white hit flash. Its config values (health, speed, contact damage, hitbox) do not change.

## Known so far

- The export has `Animations/Hornet Enemies/MossBone Crawler Anim.prefab` with clips including `Walk`, `Turn`, `Death Air`, `Death Land`, `Ambient Idle`, `Startle`, `Eat Idle`. All 12 fps.
- The hero importer (`HeroAnimationImporter`, tk2d converter) is generic in its conversion; its clip map and output folder are hero-specific.
- The enemy is drawn today by `EnemyPlaceholderView` (a coloured shape with a hit flash).

## Rules

Standing rules apply: private branches, builders never open Unity, QA is the only Unity runner (short hard time limits, one Unity at a time, never the owner's Unity), merge only after the owner says yes, no co-author lines, no edits to hand-tuned values or `SilksongEnemyConfig` values. Imported art goes in the gitignored imported folder.

## Tasks

1. **Study** (read-only): the clips, sprite collection, pivots and size of the MossBone Crawler; which clip plays when; how the sprite size compares to the creep's body collider (so it is not drawn too big or small); death clips (air vs land); how the white flash should work on a sprite; what the importer must change. Output `docs/study/17-enemy-art.md`.
2. **Importer**: extend the animation importer so an enemy clip set can be imported (map rows for Walk, Turn, Death Air, Death Land, Ambient Idle), output next to the hero art, generated and gitignored. EditMode tests for the map.
3. **Animated view**: replace the placeholder with an animated sprite view (walk, turn, death), keep the hit flash and a placeholder fallback when the art is not imported, update the room builder so Moss Creeps use it. Tests with fakes.
4. **Acceptance**: short owner checklist, a PlayMode run, a full test run, then the owner plays it.

Order: 1, 2, 3, 4.
